# dev-clis

Pequenas CLIs para desenvolvedores: contagem de linhas, portas, npm scripts e histórico do shell.

| Pasta | Repo original | Descrição |
|---|---|---|
| `ct-lines/` | [ct-lines](https://github.com/fernandobelotto/ct-lines) | A command-line tool for counting lines of code, comments, tokens and blank lines in files within a directory |
| `pscan/` | [pscan](https://github.com/fernandobelotto/pscan) | A CLI tool to interactively scan and kill processes by port number on macOS/Linux. Perfect for developers who need to quickly find and kill processes occupying specific ports. |
| `script-scan/` | [script-scan](https://github.com/fernandobelotto/script-scan) | A fast, interactive CLI for discovering and running npm scripts with fuzzy search |
| `shellmemory/` | [shellmemory](https://github.com/fernandobelotto/shellmemory) | A terminal command logger that records every command across your shell sessions directly into a SQLite database. |
